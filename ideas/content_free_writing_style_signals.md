# Content-free stylistic trajectory features (parked side-quest)

## Idea
Fingerprint the monitor on genuinely content-free features only: punctuation,
sentence-length rhythm, tool-call cadence, hesitation markers, retry patterns.
By construction these survive content controls; question is whether they carry
enough outcome signal to matter (hypothesis inspired by "formatting is noise,
process is signal" intuition).

## Why parked
P0/P1 use the richer S-space features first; this variant is a control-friendly
subset that becomes interesting only if the main line shows cross-harness
degradation of S-space features.

## Un-park trigger
P2 cross-harness gates show S-space feature AUC dropping materially under
harness shift; content-free features are the fallback representation.
